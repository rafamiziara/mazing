# mazing

**Carry your light through the maze.**

You are an ember in a maze that never ends. The flame burns down with every
step, sparks rekindle it, and a red thread — Ariadne's thread — remembers
every corridor you've dared. Find the portal before the dark catches you.

## How to play

| Command | Action |
| --- | --- |
| Arrows / WASD | Move (hold to keep scrolling) |
| Space | Echo pulse: reveals the corridors and the way out |
| M | Audio on/off |
| Esc / P | Pause |
| Swipe (touch) | Move · ◉ button for the echo |

- **The flame** — your light is your life: it fades over time and shrinks.
  Sparks ✦ rekindle it; every three sparks you earn an echo.
- **The thread** — a red thread traces your path; what you've seen remains
  in a dim purple memory.
- **The wisps** — from the third level, purple lights patrol the corridors.
  Their touch devours the flame. The echo stuns them.
- **Modes**: *Descent* (infinite levels, progressively bigger and more
  intricate) and *Daily Maze* (same maze for everyone, shareable score).

## Tech

- **Next.js 16** (App Router) + **Tailwind CSS 4** + React 19, no game
  dependencies: engine, rendering and audio are all written from scratch.
- **Seeded procedural generation** — three algorithms (recursive backtracker,
  Prim, Kruskal) with progressive *braiding* to introduce loops; mulberry32
  PRNG, FNV-1a seed (the daily maze is deterministic by date).
- **Real light**: 2D visibility polygon computed every frame (angular
  sweep over wall endpoints, collinear segments merged for performance) —
  light doesn't pass through walls.
- **Echo pulse**: animated BFS wavefront that travels along the corridors
  and a golden shortest path to the exit.
- **Synthesized audio** in WebAudio: no audio files — pentatonic plucks,
  ambient drones, whooshes and chords generated by oscillators.
- DPR-aware canvas with a chasing camera, particles, screen-shake,
  `prefers-reduced-motion` support, keyboard + touch.

## Logo

The mark — a golden maze with the red thread reaching the heart — is
available as a standalone SVG:

- `public/logo.svg` — full lockup (mark + wordmark)
- `public/logo-mark.svg` — mark only
- `src/components/Logo.tsx` — inline React components
- `src/app/icon.svg` — favicon

Designed for dark backgrounds; the colors are `#e9c57e` (gold), `#ff4d6d`
(thread), `#f2ead9` (parchment).
